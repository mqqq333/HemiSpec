    Hemisphere-specific neuroimaging toolkit

    HemiSpec

    HemiSpec is a research-software toolkit for converting preprocessed gray-matter maps into bilateral reconstruction-derived hemispheric measures: ANS (absolute neuroanatomical specificity) and RNS (relative neuroanatomical specificity).

    Quick start Input & preprocessing Installation →

    by 阿瞒的脑洞 · A MAN'S BRAINHOLE

    Asymmetry metrics

    ANS |Acti − Reconi|
    RNS |(Acti − Reconi) / (Acti + Reconi)|

    Wang et al. 2024, Patterns 5:100930

    Input boundary

    HemiSpec does not accept raw T1-weighted MRI directly as DGN input. First convert each T1 image into an MNI152 1.5 mm masked gray-matter map (*_GM_masked.nii.gz) using the documented FSL preprocessing workflow.

    End-to-end workflow

    01

    Prepare the input

    T1w NIfTI → FSL BET, FAST, affine MNI registration, GM threshold and mask → masked GM map.

    02

    Reconstruct both directions

    The packaged bilateral DGN performs left-to-right and right-to-left inference on the same preprocessed gray-matter grid.

    03

    Compute ANS and RNS

    Voxel-wise comparison yields ANS and RNS; both directions merge into bilateral target-hemisphere maps.

    04

    Summarize or validate

    Optionally aggregate with a compatible atlas, run hemisphere-classifier validation, or estimate test–retest reliability.

    ANS and RNS are non-negative reconstruction-error-derived quantities, not distances in millimetres, and not direct measurements of neuronal function, causal lateralization, or tissue pathology. The published definitions come from Wang et al. (2024); see ANS and RNS metrics for the exact software interpretation.

    Original method vs HemiSpec additions

    Original method (Wang et al. 2024)
    • Cross-hemispheric DGN reconstruction framework
    • ANS and RNS definitions
    • Published scientific evidence and terminology
    Added by HemiSpec
    • Installable API, CLI, and GUI workflow
    • Model-asset discovery and bilateral map export
    • ROI summaries, validation utilities, documentation, and release tooling

    Current scope

    Supported now

    • Voxel-wise ANS and RNS maps
    • Optional ROI tables when an atlas on the input grid is available
    • Optional hemisphere-classifier validation with the compatible Glasser atlas and labels
    • Optional test–retest reliability
    • Source checkout installation; the PyPI project is not public yet

    Not in scope

    • Raw T1-weighted images as direct DGN input
    • Behavioral-phenotype modeling as a built-in command
    • Anatomical interpretation of synthetic quickstart outputs
    • Unpublished study results

    Source of truth. This site documents the current main checkout. The archived v0.1.0 release predates some commands shown here.

    Runs. Use a new or empty output directory for each run. The GUI refuses to start when the output workspace already contains entries. In the CLI, hemispec quickstart refuses a non-empty --out-dir unless you pass --force, which deletes and regenerates that directory; hemispec workflow and the single-step commands do not check, so choose a fresh folder yourself.
